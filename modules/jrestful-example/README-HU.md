# jrestful Vert.x példa

Klasszikus Vert.x példa, amely a jrestful számlakezelő szerverét és kliensét is
tartalmazza. Egyetlen alkalmazásban mutatja be az API-felderítést, a hipermédia
által vezérelt műveleteket, a médiatípusokat, a jogosultságkezelést, valamint az
újrahasználható Vert.x kliens- és szerveradaptereket.
