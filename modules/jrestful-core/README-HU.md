# jrestful-core

A jrestful alapvető protokollmodellje és közös absztrakciói. Ez a modul írja le
a REST API-kat, az állapotátmeneteket, a relációkat, a médiatípusokat, a linkeket,
valamint a transzportfüggetlen kliens- és szerveroldali szerződéseket.

A modul nem tartalmaz HTTP runtime-ot. A modell konkrét transzporthoz
kapcsolásához valamelyik kliens- vagy szerveradaptert kell használni.
